## 💻 Run Locally

This portfolio is a **static web application**, so no frontend build system is required.

### 1. Clone the Repository

```bash
git clone https://github.com/adamellirajababu-star/rajababu-portfolio.git
```

### 2. Open the Project

```bash
cd rajababu-portfolio
```

### 3. Run Using Python

If Python is installed:

```bash
python -m http.server 3000
```

Then open:

```text
http://localhost:3000
```

### Alternative: Open Directly

You can also open:

```text
index.html
```

directly in a modern web browser.

## 🌐 Deployment

### GitHub Pages

The portfolio can be deployed using GitHub Pages.

1. Open the repository **Settings**
2. Select **Pages**
3. Under **Build and deployment**, select **Deploy from a branch**
4. Select:

```text
Branch: main
Folder: / (root)
```

5. Click **Save**

After successful deployment, the portfolio can be accessed through the GitHub Pages URL.

### Vercel

The project can also be deployed using Vercel:

1. Import the GitHub repository
2. Select the repository
3. Use the project root as the Root Directory
4. Deploy

No framework-specific build configuration is required for this static project.
