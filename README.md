## 🚀 Portfolio Features
- **Fluid Dark & Light Themes**: Real-time theme toggle with local storage persistence.
- **6 Accent Color Palettes**: Dynamic custom styling with accent glow effects (Red, Orange, Green, Blue, Purple, Rose).
- **Interactive AI Portfolio Assistant**: Embedded conversational bot capable of answering recruiter questions about skills, projects, certifications, and contact details.
- **Responsive Navigation**: Adaptive desktop navigation bar, mobile drawer menu, and right-aligned vertical section steppers.
- **Resume Hub**: Instant in-browser PDF previewing (`View Resume`) and direct local downloading (`Download Resume`).
- **Smooth Micro-Interactions**: Top scroll progress bar, scroll-to-top floating control, and subtle hover animations with zero layout shift.
- **Direct Instant Contact Hub**: 1-tap direct outreach via WhatsApp, Email, LinkedIn, and Phone.

## 💻 Run Locally
This is a pure static web application with zero external build dependencies required.
### 1. Clone the repository
```bash
git clone https://github.com/adamellirajababu-star/rajababu-portfolio.git
cd rajababu-portfolio
2. Launch Local Server
You can open index.html directly in any web browser, or run a lightweight local server:

Using Python:

bash
python -m http.server 3000
Then visit: http://localhost:3000

Using Node.js (npx):

bash
npx serve .
🏗️ Build
Because this project is built using native Vanilla Web standards (HTML5 / CSS3 / JavaScript ES6+), no compilation or bundling step is required. It runs natively in all modern web browsers.

🌐 Deployment
Method 1: GitHub Pages (Recommended)
Go to repository Settings > Pages.
Under Build and deployment > Source, select Deploy from a branch.
Set Branch to main and folder to / (root).
Click Save. The live URL will be available at:
👉 https://adamellirajababu-star.github.io/rajababu-portfolio/
Method 2: Vercel
Import repository at vercel.com/new.
Framework Preset: Other.
Root Directory: ./ (root).
Click Deploy.
